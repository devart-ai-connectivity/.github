Please check the following first:

- the repository README
- product documentation
- installation and activation guidance
- existing issues in the repository

## When to open a GitHub issue

Please open a GitHub issue when you have a reproducible problem in a repository, such as:

- a product bug
- incorrect or missing documentation
- a broken sample or setup instruction

When reporting an issue, please include:

- affected repository and product
- product version
- operating system
- AI tool used
- ODBC driver used
- steps to reproduce
- expected result
- actual result
- logs or screenshots, if available

## Sensitive information

Do not post secrets or private environment details in public issues, including:

- passwords
- API keys
- tokens
- connection strings
- customer data
- production database details

If your issue may involve a security vulnerability, please follow `SECURITY.md` instead of opening a public issue.
